# 🔇 マナーカメラ

**シャッター音が鳴らない無音カメラ**です。
撮影中も **YouTube や音楽の再生を止めません**。

ブラウザで開くだけで使える Web アプリなので、インストールは不要です（ホーム画面に追加するとアプリのように使えます）。

👉 **https://n494n0tk.github.io/camera/**
（GitHub Pages を有効にすると、この URL で開けます。手順は下の「公開のしかた」を見てください）

---

## できること

| | |
|---|---|
| 🔇 **シャッター音なし** | 撮影しても音は一切鳴りません |
| 🎵 **YouTube・音楽を止めない** | カメラを起動しても、他のアプリの再生はそのまま続きます |
| 🔄 **前面／背面カメラの切り替え** | 自撮りは「見たまま（左右反転）」で保存するかどうかを選べます |
| 🔍 **ズーム** | ピンチ、または「1×」ボタンで 2 倍に切り替え |
| ⏱ **セルフタイマー** | オフ → 3 秒 → 10 秒（カウントダウンも無音） |
| #️⃣ **グリッド線** | 3 分割のガイド線 |
| 🔦 **ライト** | 対応している端末だけ表示されます |
| 📐 **縦横比** | 4:3 / 16:9 / 1:1 |
| 🖼 **アルバム** | 撮った写真を一覧で確認し、まとめて保存・削除できます |

撮影の合図は「音」でも「白いフラッシュ」でもなく、画面が一瞬だけ暗くなるだけです。暗い場所でも周りの迷惑になりません。

## 使い方

1. iPhone は **Safari**、Android は **Chrome** で上の URL を開きます
2. 「カメラの使用を許可しますか？」と出たら **許可** を押します
3. 白い丸ボタンで撮影します
4. 左下のサムネイルからアルバムを開き、**保存** を押して端末に残します
   - **iPhone**：「保存」→ 共有メニューの **「画像を保存」** で写真アプリに入ります
   - **Android・PC**：ダウンロードフォルダに保存されます（設定で「撮影したらすぐダウンロード」もできます）

> ⚠️ アプリ内のアルバムは**一時保管**です。ブラウザのデータを消したり、しばらく使わなかったりすると消えることがあります。残したい写真は早めに「保存」してください（未保存の写真には ● が付きます）。

### ホーム画面に追加する（おすすめ）

- **iPhone**：Safari の共有ボタン →「ホーム画面に追加」
- **Android**：Chrome のメニュー →「アプリをインストール」または「ホーム画面に追加」

## しくみ

### なぜ音が鳴らないの？

普通のカメラアプリは OS の「写真を撮る」機能を使うので、シャッター音が鳴ります。
マナーカメラは、画面に映っているカメラ映像の **1 コマをそのまま切り取って画像にする** だけなので、OS のシャッター処理を通らず、音が鳴りません。

### なぜ YouTube が止まらないの？

スマホは、あるアプリが **マイク** を使ったり **音を鳴らそうとしたり** すると、他のアプリの再生を止めます。
マナーカメラはそのどちらもしません。

- カメラは **映像だけ** を使い、マイクは一切要求しない（`getUserMedia({ video: …, audio: false })`）
- 音を再生する部品（`<audio>`・`AudioContext` など）を一切使わない
- プレビュー映像の `<video>` は `muted`（消音）にして、音の主導権を取りにいかない
- Safari では Audio Session API で `navigator.audioSession.type = "ambient"`（＝他の音と混ぜる）を指定

### その他

- 写真には位置情報などの EXIF 情報は入りません
- 写真はどこにも送信されません。すべて端末の中だけで処理されます

## 注意

- **盗撮など、人の迷惑になる撮影は絶対にやめましょう。** 犯罪になります
- LINE や Instagram などの **アプリ内ブラウザ** ではカメラが使えないことがあります。Safari / Chrome で開き直してください
- カメラ映像から切り取るため、標準カメラアプリより画質が控えめになることがあります（HDR・夜景モードなどの処理はかかりません）
- 音量ボタンでの撮影には対応していません（Web アプリでは音量ボタンを扱えないため）

## 公開のしかた（GitHub Pages）

1. GitHub のこのリポジトリで **Settings → Pages** を開く
2. **Build and deployment** の **Source** を「**Deploy from a branch**」にする
3. **Branch** でこのファイルがあるブランチ（例：`main`）と `/ (root)` を選んで **Save**
4. 1〜2 分待つと `https://n494n0tk.github.io/camera/` で開けるようになります

カメラは HTTPS のページでしか使えませんが、GitHub Pages は最初から HTTPS なのでそのまま動きます。

## 手元で動かす

ビルドは不要です。静的ファイルを配信するだけで動きます。

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く（localhost ならカメラが使えます）
```
